    Tutorial de Bootstrap: Contenedores y Columnas

    1. Introducción

    Bootstrap es un framework CSS que facilita la creación de páginas web responsive, es decir, páginas que se adaptan automáticamente a diferentes tamaños de pantalla.

    En este tutorial nos centraremos en una de las partes fundamentales de Bootstrap:

    • Contenedores
    • Filas
    • Columnas
    • Sistema de 12 columnas
    • Diseño responsive
    • Breakpoints
    • Separación entre columnas
    • Anidación de columnas

    La estructura básica que utilizaremos será:

    container
   │
   └── row
        │
        ├── col
        ├── col
        └── col

    2. Preparar Bootstrap

    Para utilizar Bootstrap podemos incluirlo mediante CDN.

    Creamos un archivo index.html:

    <!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />

    <title>Bootstrap - Contenedores y columnas</title>

    <link
      href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css"
      rel="stylesheet"
    />
  </head>

  <body>
    <h1>Mi primera página con Bootstrap</h1>
  </body>
</html>

    La etiqueta:

    <meta name="viewport" content="width=device-width, initial-scale=1.0" />

    es especialmente importante cuando trabajamos con diseños responsive.

    3. ¿Qué es un contenedor?

    El contenedor es el elemento que utilizamos para organizar el contenido principal de nuestra página.

    Bootstrap proporciona principalmente dos tipos:

    .container

    y:

    .container-fluid

    3.1 .container

    La clase .container crea un contenedor con un ancho máximo que depende del tamaño de pantalla.

    Ejemplo:

    <div class="container">
  <h1>Mi página</h1>

  <p>Este contenido está dentro de un container.</p>
</div>

    El contenido no ocupa necesariamente todo el ancho de la pantalla.

    Bootstrap establece diferentes anchos máximos dependiendo del breakpoint.

    Podemos imaginarlo así:

    ┌──────────────────────────────────────────────┐
│                  navegador                   │
│                                              │
│       ┌────────────────────────────┐         │
│       │         container          │         │
│       │                            │         │
│       │       Contenido            │         │
│       │                            │         │
│       └────────────────────────────┘         │
│                                              │
└──────────────────────────────────────────────┘

    3.2 .container-fluid

    Si queremos que el contenedor ocupe todo el ancho disponible utilizamos:

    <div class="container-fluid">
  <h1>Contenido a pantalla completa</h1>
</div>

    Visualmente:

    ┌──────────────────────────────────────────────┐
│              container-fluid                 │
│                                              │
│              Contenido                       │
│                                              │
└──────────────────────────────────────────────┘

    3.3 Diferencia entre .container y .container-fluid

    Clase Comportamiento
    .container Tiene un ancho máximo responsive
    .container-fluid Ocupa el 100% del ancho
    .container-sm Ancho completo hasta sm
    .container-md Ancho completo hasta md
    .container-lg Ancho completo hasta lg
    .container-xl Ancho completo hasta xl
    .container-xxl Ancho completo hasta xxl

    Ejemplo:

    <div class="container">Contenedor normal</div>

<div class="container-fluid">Contenedor de ancho completo</div>

    3.4. Breakpoints

    Bootstrap define diferentes puntos de ruptura en función del ancho de la pantalla en la que se muestra la página

    Breakpoint Prefijo Uso aproximado
    Extra small col- Móvil
    Small sm Móvil grande
    Medium md Tablet
    Large lg Desktop
    Extra large xl Pantallas grandes
    XXL xxl Pantallas muy grandes

    4. Organización de contenido

    4.1 El sistema de filas

    Para trabajar con columnas utilizamos normalmente una fila:

    <div class="container">
  <div class="row"></div>
</div>

    La clase:

    .row

    crea una fila preparada para colocar columnas.

    La estructura habitual de Bootstrap es:

    <div class="container">
  <div class="row">
    <!-- columnas -->
  </div>
</div>

    4.2. Nuestra primera columna

    Podemos crear una columna utilizando:

    <div class="col">Columna</div>

    Ejemplo:

    <div class="container">
  <div class="row">
    <div class="col">Columna 1</div>
  </div>
</div>

    4.3 Varias columnas

    Podemos colocar varias columnas dentro de una fila:

    <div class="container">
  <div class="row">
    <div class="col">Columna 1</div>

    <div class="col">Columna 2</div>

    <div class="col">Columna 3</div>
  </div>
</div>

    Bootstrap repartirá automáticamente el espacio disponible.

    Visualmente:

    ┌──────────────────────────────────────────────┐
│                  container                   │
│                                              │
│ ┌────────────┬────────────┬────────────┐     │
│ │ Columna 1  │ Columna 2  │ Columna 3  │     │
│ └────────────┴────────────┴────────────┘     │
│                                              │
└──────────────────────────────────────────────┘

    4.4 El sistema de 12 columnas

    Una de las características más importantes de Bootstrap es su sistema de 12 columnas.

    Una fila puede dividirse en 12 unidades virtuales.

    12 columnas

┌──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┐
│  │  │  │  │  │  │  │  │  │  │  │  │
└──┴──┴──┴──┴──┴──┴──┴──┴──┴──┴──┴──┘

    Podemos repartir esas 12 unidades como queramos entre las columnas que nosotros mostremos

    Por ejemplo:

    6 + 6 = 12

    4 + 4 + 4 = 12

    3 + 3 + 3 + 3 = 12

    8 + 4 = 12

    2 + 4 + 6 = 12

    4.4.1 Columnas de 6

    Para crear dos columnas iguales:

    <div class="container">
  <div class="row">
    <div class="col-6">Columna 1</div>

    <div class="col-6">Columna 2</div>
  </div>
</div>

    Cada columna ocupa:

    6 / 12

    Por tanto:

    50% + 50%

    Visualmente:

    ┌──────────────────────────────────────────────┐
│                  container                   │
│                                              │
│ ┌────────────────────┬────────────────────┐  │
│ │      col-6         │       col-6        │  │
│ │       50%          │        50%         │  │
│ └────────────────────┴────────────────────┘  │
│                                              │
└──────────────────────────────────────────────┘

    4.4.2 Columnas de 4

    Tres columnas de 4:

    <div class="container">
  <div class="row">
    <div class="col-4">Columna 1</div>

    <div class="col-4">Columna 2</div>

    <div class="col-4">Columna 3</div>
  </div>
</div>

    Tenemos:

    4 + 4 + 4 = 12

    Cada columna ocupa:

    4 / 12 = 33,33%

    4.4.3. Columnas de 3

    Cuatro columnas de 3:

    <div class="container">
  <div class="row">
    <div class="col-3">Columna 1</div>

    <div class="col-3">Columna 2</div>

    <div class="col-3">Columna 3</div>

    <div class="col-3">Columna 4</div>
  </div>
</div>

    Tenemos:

    3 + 3 + 3 + 3 = 12

    Cada columna ocupa el 25%.

    4.4.5 Columnas de diferentes tamaños

    No es obligatorio que todas las columnas tengan el mismo tamaño.

    Por ejemplo:

    <div class="container">
  <div class="row">
    <div class="col-8">Contenido principal</div>

    <div class="col-4">Barra lateral</div>
  </div>
</div>

    Tenemos:

    8 + 4 = 12

    Visualmente:

    ┌──────────────────────────────────────────────┐
│                                              │
│ ┌────────────────────────────┬─────────────┐ │
│ │                            │             │ │
│ │          col-8             │    col-4    │ │
│ │                            │             │ │
│ └────────────────────────────┴─────────────┘ │
│                                              │
└──────────────────────────────────────────────┘

    Este diseño es muy habitual:

    Contenido principal  →  8 columnas
Sidebar              →  4 columnas

    4.4.6 ¿Qué ocurre si nos pasamos de 12?

    Supongamos que hacemos:

    <div class="row">
  <div class="col-8">Columna 1</div>

  <div class="col-8">Columna 2</div>
</div>

    Tenemos:

    8 + 8 = 16

    Como hemos superado las 12 unidades disponibles, Bootstrap coloca las columnas que no caben en una nueva línea.

    ┌──────────────────────────────────────────────┐
│ ┌────────────────────────────┐               │
│ │           col-8            │               │
│ └────────────────────────────┘               │
│                                              │
│ ┌────────────────────────────┐               │
│ │           col-8            │               │
│ └────────────────────────────┘               │
└──────────────────────────────────────────────┘

    Esto puede ser útil para entender cómo funciona el sistema de rejilla.

    4.5 .col frente a .col-6

    Tenemos:

    <div class="col">Columna</div>

    y:

    <div class="col-6">Columna</div>

    No significan exactamente lo mismo.

    .col

    Bootstrap calcula automáticamente el espacio disponible.

    Ejemplo:

    <div class="row">
  <div class="col">1</div>
  <div class="col">2</div>
  <div class="col">3</div>
</div>

    Las tres columnas tendrán aproximadamente el mismo tamaño.

    .col-6

    Estamos indicando explícitamente que la columna debe ocupar 6 de las 12 unidades:

    <div class="col-6">Columna</div>

    Es decir:

    6 / 12 = 50%

    4.6 Columnas responsive

    Una de las características más importantes de Bootstrap es que podemos cambiar el tamaño de las columnas dependiendo del tamaño de pantalla.

    Por ejemplo:

    <div class="container">
  <div class="row">
    <div class="col-12 col-md-6">Columna 1</div>

    <div class="col-12 col-md-6">Columna 2</div>
  </div>
</div>

    Aquí tenemos:

    Pantallas pequeñas:

12 + 12

    Por tanto:

    ┌──────────────────────────────┐
│          Columna 1           │
├──────────────────────────────┤
│          Columna 2           │
└──────────────────────────────┘

    En pantallas md o superiores:

    6 + 6

    Por tanto:

    ┌───────────────────┬───────────────────┐
│     Columna 1     │     Columna 2     │
└───────────────────┴───────────────────┘

    4.6.1 ¿Qué significa col-md-6?

    La clase:

    col-md-6

    puede dividirse conceptualmente:

    col  → columna

md   → breakpoint

6    → número de columnas

    Por tanto:

    col-md-6

    significa:

    A partir del breakpoint md, esta columna ocupará 6 de las 12 unidades.

    4.7 Breakpoints

    Bootstrap dispone de varios breakpoints:

    Breakpoint Tamaño mínimo
    xs < 576px
    sm 576px
    md 768px
    lg 992px
    xl 1200px
    xxl 1400px

    En las clases normalmente no escribimos xs.

    Por ejemplo:

    col-12

    se aplica desde el tamaño más pequeño.

    Mientras que:

    col-md-6

    se aplica a partir de md.

    4.7.1 Ejemplo responsive completo

    Vamos a crear tres columnas.

    En móvil:

    12
12
12
...

    En tablets:

    6 - 6
6 - 6
6 ...

    En pantallas grandes:

    4 - 4 - 4
4 - 4 - 4
4 ...

    Código:

    <div class="container">
  <div class="row">
    <div class="col-12 col-md-6 col-lg-4">Columna 1</div>

    <div class="col-12 col-md-6 col-lg-4">Columna 2</div>

    <div class="col-12 col-md-6 col-lg-4">Columna 3</div>
  </div>
</div>

    La lectura sería:

    col-12
    ↓
Móvil → ocupa todo el ancho

col-md-6
    ↓
Desde md → ocupa la mitad

col-lg-4
    ↓
Desde lg → ocupa un tercio

    4.7.2. Ejemplo visual responsive

    Móvil
    ┌───────────────────────┐

├───────────────────────┤
│       Columna 2       │

    Tablet

│  Columna 1   │  Columna 2   │  Columna 3   │
└──────────────┴──────────────┴──────────────┘

    4.7.3 Un ejemplo de página real

    Podemos utilizar el sistema de columnas para crear una página típica.

    <div class="container">
  <div class="row">
    <main class="col-12 col-lg-8">
      <h1>Contenido principal</h1>

      <p>Este es el contenido principal de nuestra página.</p>
    </main>

    <aside class="col-12 col-lg-4">
      <h2>Sidebar</h2>

      <p>Información adicional.</p>
    </aside>
  </div>
</div>

    En móvil:

    ┌──────────────────────────────┐
│       Contenido              │
├──────────────────────────────┤
│       Sidebar                │
└──────────────────────────────┘

    En escritorio:

    ┌──────────────────────────────┬─────────────┐
│                              │             │
│      Contenido principal     │   Sidebar   │
│                              │             │
└──────────────────────────────┴─────────────┘

    4.8 Añadir bordes para visualizar las columnas

    Durante el aprendizaje puede ser muy útil poner bordes.

    Bootstrap proporciona:

    border

    Por ejemplo:

    <div class="container border">
  <div class="row border">
    <div class="col-4 border">Columna 1</div>

    <div class="col-4 border">Columna 2</div>

    <div class="col-4 border">Columna 3</div>
  </div>
</div>

    Esto nos permite visualizar claramente:

    container
   ↓
┌──────────────────────────────────────┐
│ row                                  │
│ ┌──────────┬──────────┬──────────┐   │
│ │ col-4    │ col-4    │ col-4    │   │
│ └──────────┴──────────┴──────────┘   │
└──────────────────────────────────────┘

    4.8.1. Añadir espacio interior

    Podemos utilizar p-* para añadir padding.

    Por ejemplo:

    <div class="col-4 border p-3">Columna 1</div>

    p-3 significa:

    padding

    en los cuatro lados.

    También podemos utilizar:

    p-1 p-2 p-3 p-4 p-5
    4.8.2 Añadir margen

    Para añadir margen podemos utilizar:

    m-3

    Por ejemplo:

    <div class="container">
  <div class="row">
    <div class="col-4 border m-3">Columna</div>
  </div>
</div>

    Recordemos:

    padding → espacio interior

margin  → espacio exterior

    4.8.3 Gutters: separación entre columnas

    Bootstrap permite controlar el espacio entre columnas mediante las clases g-*.

    Por ejemplo:

    <div class="container">
  <div class="row g-3">
    <div class="col-4">
      <div class="border p-3">Columna 1</div>
    </div>

    <div class="col-4">
      <div class="border p-3">Columna 2</div>
    </div>

    <div class="col-4">
      <div class="border p-3">Columna 3</div>
    </div>
  </div>
</div>

    Podemos utilizar:

    g-0
g-1
g-2
g-3
g-4
g-5
    4.8.4 Diferencia entre gap, margin y gutters

    Es importante no confundir estos conceptos.

    Bootstrap dispone de diferentes mecanismos para separar elementos.

    Por ejemplo:

    <div class="row g-3"></div>

    controla el espacio entre las columnas de una fila.

    Mientras:

    <div class="p-3"></div>

    añade espacio interior.

    Y:

    <div class="m-3"></div>

    añade espacio exterior.

    Podemos resumirlo:

    g-* → separación del sistema de columnas

p-* → padding

m-* → margin

    4.9 Columnas sin especificar tamaño

    También podemos mezclar columnas automáticas con columnas de tamaño determinado.

    Por ejemplo:

    <div class="row">
  <div class="col">Columna automática</div>

  <div class="col-6">Columna de 6</div>
</div>

    Bootstrap calculará el espacio restante para .col.

    4.9.1 Columnas con diferentes tamaños

    Otro ejemplo:

    <div class="row">
  <div class="col-3">3 columnas</div>

  <div class="col-6">6 columnas</div>

  <div class="col-3">3 columnas</div>
</div>

    Tenemos:

    3 + 6 + 3 = 12

    Visualmente:

    ┌─────────┬──────────────────┬─────────┐
│  col-3  │      col-6       │  col-3  │
└─────────┴──────────────────┴─────────┘

    30. Anidar filas y columnas

    También podemos introducir una nueva fila dentro de una columna.

    Ejemplo:

    <div class="container">
  <div class="row">
    <div class="col-8">
      <h1>Contenido principal</h1>

      <div class="row">
        <div class="col-6">Subcolumna 1</div>

        <div class="col-6">Subcolumna 2</div>
      </div>
    </div>

    <div class="col-4">Sidebar</div>
  </div>
</div>

    La estructura sería:

    container
│
└── row
    │
    ├── col-8
    │   │
    │   └── row
    │       ├── col-6
    │       └── col-6
    │
    └── col-4

    Esto permite crear estructuras complejas.

    31. Regla fundamental de Bootstrap Grid

    Una regla muy importante:

    .container
    ↓
.row
    ↓
.col

    Es decir:

    <div class="container">
  <div class="row">
    <div class="col">Contenido</div>
  </div>
</div>

    Cuando trabajemos con el sistema Grid, esta estructura nos evitará muchos problemas.

    33. Analizando el ejemplo

    La estructura principal es:

    container
│
└── row
    │
    ├── col-12 col-lg-8
    │   │
    │   └── row
    │       │
    │       ├── col-12 col-md-6 col-xl-4
    │       ├── col-12 col-md-6 col-xl-4
    │       └── col-12 col-md-6 col-xl-4
    │
    └── col-12 col-lg-4

    Esto nos permite crear diferentes diseños dependiendo del tamaño de pantalla.

    40. Resumen

    Las clases fundamentales que debemos recordar son:

    Contenedores

    container container-fluid

    Filas

    row

    Columnas

    col col-6 col-4 col-3

    Columnas responsive

    col-12 col-sm-6 col-md-6 col-lg-4 col-xl-3

    Espaciado

    g-3 m-3 p-3

    Bordes

    border

    41. La idea fundamental

    El sistema Grid de Bootstrap puede resumirse en:

                CONTAINER
                │
                ▼
               ROW
                │
        ┌───────┼───────┐
        ▼       ▼       ▼
      COL      COL      COL

    Y recordar siempre:

    12 columnas = ancho completo de una fila

    Por ejemplo:

    6 + 6       = 12
4 + 4 + 4   = 12
3 + 3 + 3 + 3 = 12
8 + 4       = 12
3 + 6 + 3   = 12

    Para diseños responsive:

    col-12 col-md-6 col-lg-4

    significa:

    Móvil       → 12
Tablet      → 6
Escritorio  → 4

    42. Chuleta rápida

    ┌─────────────────────────────────────────────┐
│ CONTAINER                                   │
│                                             │
│   ┌─────────────────────────────────────┐   │
│   │ ROW                                 │   │
│   │                                     │   │
│   │ ┌────────┬────────┬────────┐        │   │
│   │ │ COL    │ COL    │ COL    │        │   │
│   │ │        │        │        │        │   │
│   │ └────────┴────────┴────────┘        │   │
│   │                                     │   │
│   └─────────────────────────────────────┘   │
│                                             │
└─────────────────────────────────────────────┘

    Principales clases

    .container          → contenedor responsive
.container-fluid    → ancho completo

.row                → fila

.col                → columna automática
.col-6              → 6/12
.col-4              → 4/12
.col-3              → 3/12

.col-md-6           → 6 columnas desde md
.col-lg-4           → 4 columnas desde lg

.g-3                → separación entre columnas

.p-3                → padding

.m-3                → margin

.border             → borde

    Patrón que debemos memorizar

    <div class="container">
  <div class="row">
    <div class="col">Contenido</div>
  </div>
</div>

    Y para responsive:

    <div class="col-12 col-md-6 col-lg-4">Contenido</div>

    Idea clave: Bootstrap Grid no consiste simplemente en poner columnas. Consiste en dividir cada fila en 12 unidades y decidir cuántas unidades ocupará cada elemento en cada tamaño de pantalla.
