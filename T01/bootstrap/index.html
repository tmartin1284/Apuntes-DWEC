    Bootstrap — Pinceladas fundamentales

    1. ¿Qué es Bootstrap?

    Bootstrap es un framework CSS/JS que proporciona:

    • Un sistema de grid responsive.
    • Clases CSS ya preparadas.
    • Componentes visuales: botones, cards, navbar, modales, alertas...
    • Utilidades para espaciado, colores, tamaños, display, flexbox, etc.
    • Componentes interactivos mediante JavaScript.

    La idea fundamental:

    En lugar de escribir todo el CSS desde cero, utilizamos clases que Bootstrap ya proporciona.

    Por ejemplo, en CSS tradicional:

    <button class="boton">Guardar</button> .boton { background-color: #0d6efd;
color: white; padding: 10px 20px; border: none; border-radius: 5px; }

    Con Bootstrap:

    <button class="btn btn-primary">Guardar</button>

    Bootstrap ya se encarga de gran parte del estilo.

    2. Incluir Bootstrap

    La forma más sencilla para empezar es mediante CDN.

    <!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />

    <title>Mi página</title>

    <link
      href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css"
      rel="stylesheet"
    />
  </head>

  <body>
    <h1>Hola Bootstrap</h1>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>
  </body>
</html>

    Idea importante

    Bootstrap tiene dos partes principales:

    Bootstrap

    • CSS → estilos, grid, utilidades, componentes visuales
    • JavaScript → componentes interactivos

    Muchísimas cosas funcionan únicamente con CSS:

    <button class="btn btn-primary">Botón</button>

    Pero otras necesitan JavaScript:

    Modal Dropdown Carousel Collapse Offcanvas Tooltip, etc.

    3. El sistema de Grid

    Probablemente sea uno de los conceptos más importantes de Bootstrap.

    Bootstrap utiliza un sistema de 12 columnas.

    La estructura habitual es:

    Columna 1
    Columna 2
    Columna 3

    Visualmente:

    ┌────────────────────────────────────┐ │ container │ │ │ │ ┌──────────┬──────────┬──────────┐ │ │ │ col │ col │ col │ │ │ │ 4/12 │ 4/12 │ 4/12 │ │ │ └──────────┴──────────┴──────────┘ │ └────────────────────────────────────┘

    También podemos especificar el número de columnas:

    <div class="row">
  <div class="col-4">4 columnas</div>

  <div class="col-8">8 columnas</div>
</div>

    Como:

    4 + 8 = 12 4. Responsive Design

    Aquí aparece una de las grandes ventajas de Bootstrap.

    Podemos indicar diferentes tamaños dependiendo del dispositivo.

    <div class="row">
  <div class="col-12 col-md-6 col-lg-4">Producto</div>

  <div class="col-12 col-md-6 col-lg-4">Producto</div>

  <div class="col-12 col-md-6 col-lg-4">Producto</div>
</div>

    Esto significa:

    Móvil: ┌──────────────┐ │ Producto │ ├──────────────┤ │ Producto │ ├──────────────┤ │ Producto │ └──────────────┘

    Tablet: ┌───────┬───────┐ │ Prod. │ Prod. │ ├───────┴───────┤ │ Producto │ └───────────────┘

    Desktop: ┌───────┬───────┬───────┐ │ Prod. │ Prod. │ Prod. │ └───────┴───────┴───────┘

    Las clases:

    col-12 → móvil col-md-6 → desde tamaño md col-lg-4 → desde tamaño lg

    5. Breakpoints

    Bootstrap define diferentes puntos de ruptura.

    Breakpoint Prefijo Uso aproximado
    Extra small col- Móvil
    Small sm Móvil grande
    Medium md Tablet
    Large lg Desktop
    Extra large xl Pantallas grandes
    XXL xxl Pantallas muy grandes

    Por ejemplo:

    <div class="col-12 col-sm-6 col-lg-3">

    Se puede interpretar como:

    • xs → 12 columnas. Es decir, en una pantalla pequeña, las columnas de nuestra tabla van a ocupar las 12 columnas del grid, con lo que se verán los elementos apilados
    • sm → 6 columnas. En una pantalla mediana, las columnas del contenedor van a ocupar 6 columnas del grid. Se verán dos elementos en paralelo.
    • lg → 3 columnas. en pantallas grandes, ocuparán 3 columnas del grid, con lo que cabrán 4 elementos

    6. Container

    Normalmente trabajaremos dentro de un container.

    <div class="container">
    <h1>Mi página</h1>
</div>

    Bootstrap centra el contenido y controla su anchura máxima.

    También existe:

    <div class="container-fluid">
    Contenido a todo el ancho
</div>

    Diferencia:

    .container

    ┌──────────────────────────────┐ │ │ │ CONTENIDO CENTRADO │ │ │ └──────────────────────────────┘

    .container-fluid

    ┌────────────────────────────────────────────┐ │ CONTENIDO A TODO EL ANCHO │ └────────────────────────────────────────────┘

    Mientras que el container se centra en la página y muestra "márgenes" a los lados, el fluid container se adapta al ancho de la página y la ocupa entera. Si además lo mezclamos con los breakpoints conseguimos páginas que ocupan toda la pantalla

    23. Algo importante: Bootstrap no sustituye a CSS Es importante transmitir esto a los alumnos. Bootstrap no pretende eliminar CSS. Lo normal es combinar: Bootstrap + CSS propio + JavaScript propio Por ejemplo:
    ...
    Bootstrap: .card { ... } Nuestro CSS: .mi-producto { transition: transform 0.2s; } .mi-producto:hover { transform: translateY(-5px); } Bootstrap nos proporciona una base y nosotros podemos personalizarla. 24. Regla práctica para aprender Bootstrap Ante un problema de diseño, podemos pensar: ¿Bootstrap tiene una clase para esto? │ ├── Sí → utilizarla │ └── No → escribir CSS propio Por ejemplo: "Quiero centrar horizontalmente este elemento."
